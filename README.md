# Trace

「Trace」是一款日記與目標追蹤 iOS App，旨在幫助使用者紀錄日常、設定目標，並回顧自己的成長軌跡。

> **課程專案**：國立臺灣科技大學｜113.2｜CS3042701｜iOS 程式設計｜期末專案

## 專案狀態

本專案是 113.2 臺科 CS3042701「iOS 程式設計」期末專案。課程展示與公開整理已完成，後續不再持續維護。

## 功能特色

- **心情日記**：每日可記錄多篇日記，包含標題、內文、心情指數 (1-5分) 及多張照片。
- **目標與夢想**：
    - **具體目標**：設立有明確截止日期和進度條的短期目標。
    - **抽象夢想**：記錄沒有固定時程的長期願景。
- **建立連結**：可將單篇日記與特定目標或夢想關聯，追蹤努力的點滴。
- **主頁儀表板**：
    - 快速瀏覽最重要的夢想和即將到期的目標。
    - 快速新增日記與目標。
    - 提醒即將到期或久未更新的目標。
    - 顯示最新的日記。
- **成長回顧**：
    - **熱力圖 (Growth Grid)**：以類似 GitHub貢獻圖的視覺化方式，呈現整年度的日記撰寫頻率。
    - **數據統計**：統計今年、本月、本週的日記數量與完成的目標數。
    - **隨機回顧**：隨機展示過去一週、一個月的日記，重溫回憶。
    - **一年前的今天**：喚醒塵封的記憶。

## 技術棧

- **UI**：SwiftUI
- **數據持久化**：SwiftData
- **照片選取**：PhotosUI
